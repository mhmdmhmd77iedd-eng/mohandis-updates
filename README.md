# تحديثات المهندس

هذا المستودع عام، وبيه بس ملفات التحديث لواجهة **المهندس**:

- `update.json`: آخر نسخة (العادية والتجريبية). الشاشات تشيك عليه كل ٦ ساعات.
- `apk/`: ملفات التطبيق.
- `waze-links.json`: روابط نسخ ويز المناسبة لكل شاشة.

الكود نفسه بمستودع خاص.
- `s/`: صفحة «دز للسيارة» بالتلفون (تنفتح من GitHub Pages). الزبون يصوّر رمز الشاشة مرة وحدة، وبعدها يدز الطريق من مشاركة ويز. رابط اختصار الآيفون الجاهز بـ `s/config.json`.
